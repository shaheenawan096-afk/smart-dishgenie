# Smart DishGenie (online version)

AI recipe assistant: ingredients in English / Roman Urdu / Urdu -> dishes that suit the weather and the time of day.

This is the lightweight online version for Streamlit Community Cloud. It includes ingredient understanding
(Module 1), the weather and meal-time labels of Module 2, live weather and recipe ranking.
Voice, photo input, translation and AI dish pictures need large models and are available in the full desktop version.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`
